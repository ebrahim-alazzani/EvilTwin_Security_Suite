# EvilTwin Security Suite - حزمة محاكاة وفحص الشبكات اللاسلكية

مشروع تعليمي وأكاديمي تم تطويره وتوحيده من النسخ الطلابية المختلفة لدراسة وفهم هجمات نقاط الوصول الوهمية (Rogue Access Points) المعروفة بـ **Evil Twin** وكيفية اكتشافها والوقاية منها.

---

## 🎯 أهداف المشروع

1. **الجانب الدفاعي (Defense & Detection)**: فحص شبكات الواي فاي المحيطة ومطابقة عناوين الـ BSSID والـ SSID لاكتشاف أي تكرار مريب أو تزييف لمعرفات الشبكة.
2. **محاكاة آليات البث (Simulation)**: محاكاة أسلوب بث نقاط الوصول واختبار اتصال الأجهزة لغايات التدريب الأمني واختبار البيئات المعزولة.
3. **توثيق تاريخي**: حفظ كافة النسخ والمراحل التجريبية السابقة للمشروع في مجلد مخصص مع مقارنة الفروق بينها.

---

## 📁 هيكلية المشروع الموحد

```text
EvilTwin_Security_Suite/
├── core/
│   ├── attacker.py          # خادم محاكاة نقطة الوصول وتلقي بيانات الاتصال
│   ├── detector.py          # كاشف ومحلل الشبكات لاكتشاف الـ Evil Twin
│   └── mitm_utils.py        # دوال مساعدة لإدارة توجيه الحزم في بيئات لينكس
├── archive_versions/        # أرشيف منظم للنسخ الثمانية السابقة
│   └── VERSIONS_HISTORY.md  # جدول المقارنة والتحليل بين النسخ
├── logs/                    # مجلد حفظ سجلات جلسات الاتصال التجريبية
├── main.py                  # القائمة التفاعلية الرئيسية للتشغيل
├── requirements.txt         # متطلبات التشغيل
└── README.md                # هذا الملف التوثيقي
```

---

## 🚀 كيفية التشغيل والاستخدام

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. تشغيل القائمة الرئيسية
```bash
python main.py
```

من خلال القائمة الرئيسية، يمكنك اختيار:
- **[1] تشغيل خادم المحاكاة**: يقوم ببدء الاستماع وبث بيانات الشبكات الافتراضية.
- **[2] تشغيل كاشف ومدافع الشبكات**: يقوم بفحص الشبكات وتحديد الشبكات الآمنة والشبكات المزيفة.
- **[3] فحص بطاقات ومحولات الشبكة**: يعرض معلومات تفصيلية عن محولات الشبكة المحلية.
- **[4] عرض سجلات الاتصال**: استعراض سجلات الجلسات السابقة.
- **[5] الدليل التعليمي**: قراءة نبذة نظرية حول هجمات التوأم الشرير وطرق الحماية منها.
